# Salim Mohamed Mwamkoba — Portfolio

React + Vite portfolio prepared for Vercel.

## Local
npm install
npm run dev

## Production
npm run build

## Vercel
Import the GitHub repository into Vercel. Vercel detects Vite automatically. Build command: `npm run build`; output: `dist`.

Before publishing, add `public/Salim_Mwamkoba_Resume.pdf`, replace placeholder project/LinkedIn links in `src/main.jsx`, and update the email if needed.
